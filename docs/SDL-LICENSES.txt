DPT.DOOM SDL2 Windows development configuration
=============================================

The optional tools/fetch-sdl.ps1 script downloads official prebuilt packages:

SDL 2.32.10
https://github.com/libsdl-org/SDL/releases/tag/release-2.32.10

SDL_mixer 2.8.2
https://github.com/libsdl-org/SDL_mixer/releases/tag/release-2.8.2
